## Project material, not an external investigation

This is a proposal for a future discovery system. It does not recommend or verify any external repository, paper, lab, or tool.

## The question

Can a small, evidence-aware queue identify emerging public work worth reading, testing, or reusing more reliably than a stream of trending links?

## Proposed operating rule

Each run should return at most three candidates. A candidate needs a relevance rationale, activity evidence, license and security caveats, a likely learning path, a smallest next experiment, and a confidence score.

## What this does not show

No crawler or ranking system is implemented in this publication proof of concept. Human review remains necessary before any discovery becomes a factual recommendation or an article.

## Next experiment

Manually prepare three research packets using the documented template and evaluate whether each packet changes a Vale reading, testing, or build decision.
